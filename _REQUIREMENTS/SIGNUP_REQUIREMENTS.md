# 회원가입 페이지 요구사항

## 기본 정보

- [x] 아이디(이메일) - Required, 중복 확인 필수
- [x] 닉네임 - Required, 중복 확인 필수
- [x] 비밀번호 - Required, 8자 이상, 영문+숫자 조합
- [x] 비밀번호 확인 - Required, 비밀번호와 일치

## 유효성 검증

- [x] 아이디: 공백 불가, 이메일 형식 검증
  - 오류 메시지: "이메일 형식으로 작성해 주세요."
- [x] 닉네임: 공백 불가
  - 오류 메시지: "닉네임을 입력해 주세요."
- [x] 비밀번호: 공백 불가, 8자 이상, 영문+숫자 조합
  - 오류 메시지: "비밀번호는 8자 이상, 영문과 숫자 조합이어야 합니다."
- [x] 비밀번호 확인: 공백 불가, 비밀번호와 일치
  - 오류 메시지: "비밀번호가 일치하지 않습니다."

## 중복 확인

- [x] 아이디 중복 확인 버튼 (GET /api/signup/check-email)
  - [x] 유효성 검증 통과 전: 비활성화
  - [x] 유효성 검증 통과 후: 활성화
  - [x] 중복 있음: "이미 사용 중인 이메일입니다."
  - [x] 중복 없음: "사용 가능한 이메일입니다."
  - [ ] 포커스 벗어남 (미확인): 빨간 outline, "중복을 확인해 주세요"

- [x] 닉네임 중복 확인 버튼 (GET /api/signup/check-nickname)
  - [x] 유효성 검증 통과 전: 비활성화
  - [x] 유효성 검증 통과 후: 활성화
  - [x] 중복 있음: "이미 사용 중인 닉네임입니다."
  - [x] 중복 없음: "사용 가능한 닉네임입니다."
  - [ ] 포커스 벗어남 (미확인): 빨간 outline, "중복을 확인해 주세요"

## API & 네비게이션

- [x] POST /api/signup - 회원가입 요청
  - [x] body: { email, nickname, password, confirmPassword }
- [x] 회원가입 성공 → 로그인 페이지로 이동 (뒤로가기 불가)
- [x] "회원이신가요? 로그인 바로가기" 링크 → 로그인 페이지로 이동
