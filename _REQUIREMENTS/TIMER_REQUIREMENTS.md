# 타이머 페이지 요구사항

> https://docs.google.com/document/d/1WAKjAG7mbz4J38DjmH8ByLVDE-4SarLNYi7eOKRPEJA/edit?tab=t.0

## 타이머: 기본

- [ ] 초기 세팅 (GET /api/timers)
  - [ ] 진행 중인 타이머 확인 (종료되지 않은 타이머)
  - [ ] 로그아웃/강제종료/새로고침 후 재진입 시 기존 기록(시간, 목표, 할 일) 복구
  - [ ] splitTimes 배열 합산하여 화면 표시 시간 계산
  - [ ] 진행 중인 타이머 없으면 초기 상태 랜딩
- [ ] GNB 로고 클릭 시 타이머 페이지 이동
- [ ] 페이지 이탈 후 복귀 시 타이머 계속 진행 (동기화)
- [ ] 백그라운드 동작 (다른 탭 활성화 시에도 동작)

## 타이머: 시작

- [ ] 재생 버튼(▶︎) 클릭 시 모달 오픈
- [ ] 모달 입력 필드
  - [ ] 오늘의 목표 (수정 불가, 필수, 최대 30자)
  - [ ] 할 일 목록 (최소 1개 이상 필수, 최대 30자)
- [ ] '타이머 시작하기' 버튼 활성화 조건 (목표 + 할 일 1개 이상)
- [ ] 타이머 시작 요청 (POST /api/timers)
  - [ ] Body: 목표, 할 일 목록
  - [ ] Response: timerId 저장
- [ ] 시작 후 UI 변경
  - [ ] '할 일 목록' 버튼 생성
  - [ ] '초기화' 버튼 생성

## 타이머: 데이터 관리 (Polling)

- [ ] 클라이언트 타이머 연산
  - [ ] 실시간 진행 시간 관리
  - [ ] 일시정지 시간 제외
  - [ ] 일자별 재생 시간 분리 관리 (23:00 ~ 01:00 시 2일로 분리)
- [ ] 서버 동기화 (PUT /api/timers/{timerId})
  - [ ] 주기: 10분
  - [ ] Update Body: splitTimes (일자별 시간 배열), review, updatedTasks
- [ ] 일시정지 시 즉시 동기화 요청 및 폴링 중단
- [ ] 재시작 시 폴링 재개

## 타이머: 일시 정지

- [ ] 일시 정지 버튼(⎮⎮) 활성화
- [ ] 클릭 시 타이머 정지
- [ ] 정지 시점 서버 동기화 (PUT /api/timers/{timerId})
- [ ] 폴링 중단

## 타이머: 초기화

- [ ] 초기화 버튼 클릭 (재생/일시정지 상태 모두 가능)
- [ ] 서버 데이터 삭제 요청 (DELETE /api/timers/{timerId})
- [ ] 클라이언트 상태 초기화 (시간, 목표, 할 일 전체 초기화)

## 타이머: 예외 처리 (새로고침/종료)

- [ ] 비정상 종료 시 서버 데이터 유지 (DELETE 요청 안 함)
- [ ] 재진입 시 (GET /api/timers) 조회하여 상태 복구
  - [ ] splitTimes 누적 관리
  - [ ] 목표/할 일 목록 복구

## 타이머: 할 일 관리

- [ ] '할 일 목록' 버튼 클릭 시 모달 오픈
- [ ] 할 일 목록 조회 (GET /api/study-logs/{studyLogId} 또는 로컬 상태)
- [ ] 할 일 추가 (모달 상단 입력)
- [ ] 할 일 완료 토글 (아이템 클릭 / 체크박스)
- [ ] 할 일 수정 (연필 아이콘 -> 텍스트 수정 -> 체크 확인)
- [ ] 할 일 삭제 (휴지통 아이콘)
- [ ] 변경 사항 저장 (PUT /api/{studyLogId}/tasks)
- [ ] 모달 닫기 방지 (취소/저장 버튼으로만 닫힘)

## 타이머: 종료

- [ ] 종료 버튼(◼︎) 클릭 시 모달 오픈
- [ ] 할 일 목록 최종 확인 및 수정 (추가/삭제/토글 가능)
- [ ] 학습 회고 작성
  - [ ] 필수 (15자 ~ 500자)
  - [ ] 텍스트만 가능
- [ ] '공부 완료하기' 버튼
  - [ ] 회고 15자 이상 시 활성화
- [ ] 종료 요청 (GET /api/timers/{timerId}/stop ?? -> 명세 확인 필요)
  - [ ] Body: 최종 할 일, 회고, splitTimes
- [ ] 성공 시 초기 상태로 리셋
